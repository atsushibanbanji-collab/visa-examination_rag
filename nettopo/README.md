# NetTopo — ネットワーク構成図エディタ

**⚠️ 本ディレクトリはビザ検定アプリとは無関係の、独立した趣味プロジェクトです。**
リポジトリ内の他のコード（backend/・frontend/ 等）とは依存関係が一切ありません。

ブラウザだけで動く、ネットワーク構成図（トポロジ）を自由にカスタマイズできる
エディタです。サーバ・ビルド・インストール不要。

## 使い方

`nettopo/index.html` をブラウザで開くだけで動きます。
（ローカルサーバ経由でもOK: `cd nettopo && python -m http.server 8080`）

- **機器パレット**: クリックでノード追加（ルーター・スイッチ・FW・サーバ等14種）
- **選択モード（V）**: ノードをドラッグで移動、クリックで選択して右パネルで編集
- **接続モード（C）**: ノードを2つ順にクリックして線でつなぐ
- **削除モード（D）**: クリックしたノード・線を削除（Del キーでも可）
- **右パネル**: 機器ごとに 名称／種別／IPアドレス／**要件**／**メモ** を記入できる
  （記入があるノードには 📝 マークが付く）。接続線はラベル・線種（実線/破線）を編集可能
- **図面管理**: 上部バーで複数図面の切替・新規・複製・削除
- **保存**: ブラウザ（localStorage）に自動保存。JSON の書き出し／読み込みにも対応
- **表示**: ホイールでズーム、背景ドラッグでパン、グリッド吸着、全体表示ボタン

## データ構造

図面1枚は次の素朴な JSON（書き出しファイルと同じ形式）:

```json
{
  "id": "dg_...", "name": "図面名",
  "nodes": [{ "id": "nd_...", "type": "router", "label": "RT-01",
              "ip": "192.168.0.1/24", "requirements": "要件", "memo": "メモ",
              "x": 460, "y": 320 }],
  "links": [{ "id": "lk_...", "from": "nd_...", "to": "nd_...",
              "label": "1Gbps", "style": "solid" }]
}
```

## ロードマップ（段階的に拡張予定）

1. ✅ **段階1（現状）**: ブラウザ内で完結する編集UI（localStorage保存・JSON入出力）
2. ⬜ **段階2**: サーバ＋データベース保存（アカウントごとに図面を永続化）。
   上記 JSON をそのまま API へ送る想定でデータ構造を設計済み
3. ⬜ 以降の候補: 図面の共有・PNG/SVG書き出し・Undo/Redo・機器テンプレート
