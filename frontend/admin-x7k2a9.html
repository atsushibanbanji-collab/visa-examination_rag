問題管理

CSVで問題を編集する。エクスポート→Excelで編集→アップロードの流れ。 列は id, level, unit, category, question, choice_1, choice_2, choice_3, answer, explanation。 answer は 1〜3（choice_N の N に対応）。 unit は単元ID（basics, b_visa, e_visa, l_visa, h1b_visa, f_visa, j_visa, green_card）。空でも取り込み可能だが、その問題は単元クイズに出題されない（卒業試験には含まれる）。 unit 列なしの旧CSVも互換のため受け付ける（警告扱い）。 BOM 付き UTF-8 / Shift-JIS どちらでも取り込み可能。
